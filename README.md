Invent a Word We Need: one new English word, defined in a single clear line.

**roomember** — the flash of remembering why you entered a room, arriving the instant you step back out of it.

Everyone knows the moment: you walk into a room with a purpose, the purpose evaporates on arrival, and the second you step back out — there it is again. English has no word for that doorway amnesia and its instant return. *Roomember* fills the gap: room + remember, sayable at first sight, spelled the way it sounds, and memorable because the feeling is universal.

## Run it

```sh
python3 main.py
```

Writes the 106-character entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Pure Python standard library, no dependencies, deterministic.
